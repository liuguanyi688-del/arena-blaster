# 项目经历：ARENA BLASTER — 浏览器 3D 肉鸽 FPS

> 一句话：用 Three.js + AI 辅助开发，从零搓出一个**零构建、纯前端、可直接上线**的 3D 射击游戏，
> 含双模式（经典 10 杀 / 肉鸽生存）、三武器、强化三选一、完整敌人 AI 与打击反馈体系。

---

| 类型 | 个人项目 / WebGL 游戏 / 肉鸽 FPS |

| 线上 | GitHub Pages 部署，HTTPS + 静态托管，局域网联机支持 |

## 核心工作

- **渲染架构**：Three.js 零构建方案——原生 ES Modules + importmap 本地化引擎与加载器
  （FBX/GLTF/SkeletonUtils），不依赖任何 CDN 与打包工具，改代码刷新即玩
- **场景程序化生成**：运行时测量 6 套素材包 250+ 构件的包围盒，自动居中/落地/生成碰撞体，
  拼装出含中央遗迹、城堡塔楼、石墙堡垒、掩体群的完整竞技场；**同材质静态网格合并**压降 draw call
- **FPS 手感层**：Pointer Lock 视角、加速度/摩擦力移动模型、Shift 冲刺、Q 冲刺技能、
  机瞄 FOV 缩放（灵敏度随倍率自适应）、连发散布 + 后坐力曲线、动态准星
- **战斗系统**：三武器体系（步枪/冲锋枪/狙击，各自弹道/弹匣/镜倍率）、hitscan 射击 +
  隐形碰撞盒（身体/爆头两档）、穿透弹、暴击、高爆弹头范围伤害
- **敌人 AI**：状态机（巡逻→视线发现→追击→横移点射）、射线视线遮挡检测、前向避障探测、
  个体速度差异化、精英波、波次属性成长曲线（刻意调温和保爽杀体验）
- **肉鸽强化层**：16 种强化卡（常见/稀有/史诗三档加权抽取），覆盖数值/机制/技能三类——
  含相位冲刺、二段跳、穿透、爆炸弹、吸血、暴击等机制型强化，每波肃清后三选一即刻生效
- **打击反馈体系**：hit marker、伤害飘字（DOM 3D 投影）、击杀播报、受击红闪 + 屏幕震动、
  枪口光源池、曳光/火花/烟雾粒子、镜筒 UI
- **工程化细节**：帧驱动流程调度（免疫后台标签页冻结）、主循环异常捕获上报、
  自适应分辨率（<45fps 自动降采样）、设置项 localStorage 持久化、静态资源禁缓存开发服务器

## 排查解决的关键问题（亮点）

1. **实例属性遮蔽原型方法**导致渲染循环每帧异常、画面冻结——通过自建
   「异常写窗口标题」的远程诊断机制 10 分钟定位，修复后建立主循环 try/catch 上报规范
2. 动态增删点光源触发 Three.js **着色器重编译**造成连发卡顿——改为常驻光源池，只调强度
3. 骨骼动画网格（SkinnedMesh）**射线检测不可靠**——改用 CS 式隐形碰撞盒，顺带实现爆头判定
4. FBX 动画与模型**骨骼命名不一致**导致 T-pose——按后缀模糊匹配重映射动画轨道
5. 后台标签页 setTimeout 冻结导致流程卡死——全流程计时器改造为**帧驱动**
6. 跨文件浏览器缓存陈旧 JS 造成"改了不生效"——自写 no-cache 静态服务器 + 依赖完整性扫描脚本

## 成果

- 功能全链路自动化验证通过：开局→移动→命中→击杀→死亡→重生→胜利结算，零循环异常
- 双模式 + 三武器 + 16 强化 + 4 类敌人行为 + 完整部署链路（本地/局域网/GitHub Pages）
- 全程 AI 结对开发：问题定位 → 方案设计 → 实现与回归验证均由 AI 主导，人类负责试玩反馈
