# ARENA BLASTER — 3D FPS

Three.js + Kenney CC0 素材的浏览器 FPS。两种模式：**经典**（10 杀获胜）与**生存**（波次递增 + 每 10 波 BOSS）。
WASD 移动、鼠标视角、左键射击、右键机瞄、Shift 奔跑、Q 冲刺（需强化解锁）、1~4 或滚轮切换**四种武器**。

> 📚 **文档**：[项目经历](docs/项目经历.md) · [教学文档](docs/教学文档.md)（含架构讲解与踩坑实录）

## 玩法 / 系统

- **四种武器**：脉冲步枪（全能）/ 蜂刺冲锋枪（高射速大弹匣）/ 重击狙击（半自动高倍镜，爆头必杀）/ 霰弹爆破者（6 弹丸扇形）
- **肉鸽强化**：16 种（数值/机制/技能三类），波次肃清后按 1/2/3 三选一——含相位冲刺、二段跳、贯穿弹、高爆弹头、狂乱等
- **兵种体系**：突击兵 / 冲锋兵（速快血薄）/ 重装兵（2.6 倍血），第 2/3 波起渐进混入；每 5 波精英、每 10 波 **BOSS**（扇形弹幕 + 冲撞）
- **战斗节奏**：敌人攻速刻意压制 + 全局攻击名额（最多 2 人同时开火）——爽杀体验优先
- **打击反馈**：伤害飘字（爆头红字放大/暴击）、hit marker、敌人红闪、火花、受击震屏（强度可调）、重kill慢动作
- **击杀掉落**：药水回血、弹匣补弹，走近自动拾取，低血量掉率提升
- **精英/BOSS 血条**、击杀播报带兵种名、新手引导逐条提示（设置可关）
- **经典模式**：敌人无限复活，先拿 10 杀获胜，结算命中率
- **生存模式**：波间补给，阵亡结算本局 Build 与历史最佳
- **战绩页**：总击杀 / 场次 / 最佳生存（主菜单「战绩」查看）
- **设置**：灵敏度 / 音量 / FOV / 反转 Y / 帧率显示 / 震屏强度 / 新手引导（localStorage 持久化）

## 技术

- Three.js 0.170 本地化 `lib/`（零 CDN、零构建，ES Modules + importmap）
- 场景由 mini-arena / castle-kit / mini-dungeon 构件自动拼装，**同材质静态网格合并**压 draw call
- 帧率显示 + 自适应分辨率（<45fps 自动降采样保流畅）
- 黄昏氛围（ACES 色调映射 + 天空渐变 + 暖雾）+ 环境风声 + 战斗低音渐入 + 脚步声
- GitHub Actions CI：push 时自动做模块语法检查与 importmap 依赖完整性校验
- 素材全部来自 [kenney.nl](https://kenney.nl)，CC0 协议；代码 MIT

## 操作

| 按键 | 功能 |
|---|---|
| W A S D | 移动 |
| 鼠标 | 视角 |
| 左键（按住） | 连发射击 |
| 右键（按住） | 机瞄：视野拉近、散布减小、灵敏度降低 |
| 空格 | 跳跃（解锁浮空靴后支持二段跳） |
| Shift | 奔跑（精度下降） |
| Q | 相位冲刺（需肉鸽强化解锁） |
| R | 换弹 |
| 1 2 3 4 / 滚轮 | 切换武器（波次肃清后的强化选择也是按 1/2/3） |
| Esc | 释放鼠标（暂停，点任意位置继续） |

## 运行

双击 **`启动游戏.bat`**（自动启动本地服务器并打开浏览器，保持黑窗口开着即可）。

局域网联机（朋友同 WiFi 浏览器打开你的 IP 即可）：

```
python serve.py 8082 --public
```

浏览器打开 http://localhost:8082 。选择模式后点击按钮进入战场。

> 8082 端口带禁缓存头保证代码最新；旧标签页请关掉。切走浏览器窗口游戏会自动暂停
> （浏览器对后台标签页的行为），回来后点任意位置继续。
