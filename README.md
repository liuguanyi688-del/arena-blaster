# ARENA BLASTER — 3D FPS

Three.js + Kenney CC0 素材的浏览器 FPS。两种模式：**经典**（10 杀获胜）与**生存**（波次递增）。
WASD 移动、鼠标视角、左键射击、右键机瞄、Shift 奔跑、1/2/3 或滚轮切换三种武器。

## 玩法 / 系统

- **三种武器**：脉冲步枪（全能）/ 蜂刺冲锋枪（高射速大弹匣）/ 重击狙击（半自动、高倍镜、爆头必杀）
- **击中反馈**：hit marker + 伤害飘字（爆头红色放大）+ 敌人红闪 + 火花 + 受击震屏
- **击杀掉落**：药水回血、弹匣补弹，走近拾取，12 秒后消失
- **敌人 AI**：巡逻 → 视线发现 → 追击 → 掩体横移点射，速度/行为个体差异化
- **经典模式**：敌人无限复活，先拿 10 杀获胜，结算命中率
- **生存模式**：一波波肃清递增强化的敌人（血量/速度/伤害/精度逐波提升），波间补给，阵亡结算撑过的波数
- **设置**：灵敏度 / 音量 / FOV / 反转 Y / 帧率显示（localStorage 持久化）

## 技术

- Three.js 0.170 本地化 `lib/`（零 CDN、零构建，ES Modules + importmap）
- 场景由 mini-arena / castle-kit / mini-dungeon 构件自动拼装，**同材质静态网格合并**压 draw call
- 帧率显示 + 自适应分辨率（<45fps 自动降采样保流畅）
- 黄昏色调（ACES 色调映射 + 天空渐变 + 暖雾）
- 素材全部来自 [kenney.nl](https://kenney.nl)，CC0 协议

| 鼠标 | 视角 |

## 运行

双击 **`启动游戏.bat`**（自动启动本地服务器并打开浏览器，保持黑窗口开着即可）。

或手动：

```
cd D:\zai\fps-shooter
python serve.py 8082
```

浏览器打开 http://localhost:8082 。选择模式后点击按钮进入战场。

> 8082 端口带禁缓存头保证代码最新；旧标签页请关掉。切走浏览器窗口游戏会自动暂停
> （浏览器对后台标签页的行为），回来后点任意位置继续。
